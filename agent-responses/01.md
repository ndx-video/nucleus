Honesty choices baked in

1. Attestation is harness-owned — models cannot write a valid artifact by hand.
2. /review blocked without attestation when attestation.required: true.
3. Reviewer context is Spec + Diff + Attestation only (bundle injected on /review).
4. Phase gates refuse illegal transitions instead of “hoping” the model behaves.
5. Accept requires review pass or an explicit human override reason.

Phase 2 (heavy tool hooks, provenance harder to fake, true forked reviewer session) is intentionally not implemented — Phase 1 stays thin. I have not committed; say if you want a commit or install smoke against a live Pi session.
